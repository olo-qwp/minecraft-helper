🛠 v1.2.0 修复（根治 iGameGod 闪退）
① %ctor 纯 C 化：注入期（main 之前）零 ObjC（连 Foundation 也不碰），专用 fprintf 早期日志 + 内存 ring buffer，躲避「类初始化在构造期崩溃」
② 导出 MSInitialize：MobileLoader/iGameGod 约定的安全时机，app 完全启动后由注入器调用，全部 ObjC/UI 初始化移到此
③ 8 秒兜底 timer：注入器不调 MSInitialize 也自动拉起；幂等守卫只初始化一次
④ iGameGod 专用 deb 用 arm64 瘦 dylib（单架构，A11 完美覆盖），避免 fat 注入兼容问题
⑤ 支持 Minecraft Preview 及所有版本：Filter 覆盖 com.mojang.minecraftpe + com.mojang.minecraftpe.preview

⚙️ 安装方式

  1. iGameGod（无越狱）：下载 MinecraftHelper-1.2.0-iGameGod.deb → Tweaks 标签 → ➕ → 新建文件夹 → Import Tweak → 选择 deb。
  2. 越狱：下载 rootless .deb，用 Sileo / Zebra / Filza 安装，重启 Minecraft。
  3. 进游戏后点屏幕右侧 MH 悬浮球打开菜单。
  4. 导出日志：菜单 → 导出日志（分享面板）/ 复制日志。
