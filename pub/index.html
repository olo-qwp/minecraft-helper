⚙️ 安装方式

  1. 越狱：下载对应 .deb，用 Sileo / Zebra / Filza 安装，重启 Minecraft。
  2. iGameGod：下载 dylib → Tweaks 标签 → ➕ → 新建文件夹 → Import Tweak → 选择文件。
  3. 进游戏后点屏幕右侧 MH 悬浮球打开菜单。
  4. 导出日志：菜单 → 导出日志（分享面板）/ 复制日志。

🧬 符号探测结果（运行日志）

  1. 启动即用 MSFindSymbol 批量探测 10 个 Bedrock C++ mangled 名
  2. 命中 → 自动按符号 hook；剥离（NULL）→ 该项显示「符号缺失」
  3. iOS MCPE 二进制已剥离符号，未命中属预期；命中即生效
  4. 所有 hook 条件化 + 空指针安全，无 substrate 环境也绝不闪退
